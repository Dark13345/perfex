# Дизайн: цветовая схема PERFEX в стиле Binance

Дата: 2026-07-06 · Статус: утверждён и реализован

## Цель

Перекрасить сайт PERFEX (36 HTML-страниц, общий `styles.css`) из сине-белой схемы в стиль Binance: тёплый графитовый тёмный интерфейс с жёлтым акцентом #F0B90B. Меняются обе темы (светлая и тёмная), тёмная — приоритет. Попутно цвета переводятся на CSS-переменные, чтобы будущие смены палитры сводились к правке одного блока токенов.

Вёрстка, типографика, отступы, HTML-файлы и картинки не меняются. Механизм переключения темы (`html.dark` + localStorage) сохраняется как есть.

## Особые случаи

- **Кнопки.** Все primary-кнопки (`.btn.primary`, `.cta`) — жёлтая заливка `--btn-bg` с тёмным текстом `--on-accent` в обеих темах (фирменный паттерн Binance). Сейчас текст кнопок белый — это меняется. `!important` в существующих правилах сохраняется как есть.
- **CTA-баннер** (`.cta-banner`, сейчас синяя полоса): становится жёлтым `#FCD535` с текстом `#181A20` в обеих темах — как промо-полосы Binance. Кнопка внутри (`.cta-banner .btn.primary`, сейчас белая с синим текстом) инвертируется: тёмная `#181A20` с текстом `#FCD535`. Фоновая картинка-оверлей не трогается.
- **Инвертированные элементы** (например, `.tab.active` в тёмной теме: светлый фон + тёмный текст) — переводятся на пару `--text`/`--bg` соответствующей темы, поведение «инверсии» сохраняется.
- **Тени** дропдаунов/мегапанели → `var(--shadow)` (убирает отдельные dark-правила про box-shadow).
- **Карта счёта Demo** (сейчас синий градиент — последний носитель старого брендового синего): переходит на жёлтый градиент `#FCD535 → #F0B90B → #C99400` с тёмным текстом. Карты Standard (серебро) и Zero (чёрная) сохраняют свои фиксированные фоны, их золотые акценты унифицируются в брендовый жёлтый.
- **`color-scheme: dark`** и переключение иконок луна/солнце в `.theme-toggle` — остаются как есть (это поведение, а не палитра).

## Чистка dark-правил

После перевода на переменные большинство из 99 правил `html.dark ...` станут дублировать базовые (то же свойство, тот же `var()`). Такие правила удаляются. Остаются только правила, где тёмная тема отличается структурно: `color-scheme`, переключение иконок темы, и случаи, где токеном не обойтись (если такие выявятся при реализации — они допустимы, но каждый должен быть осознанным исключением).

## Что не меняется

- HTML-файлы (инлайн-стилей с цветами нет — проверено), картинки, JS переключения темы/языка.
- Логотип: `.logo span` перекрашивается токеном (`--accent-text`), файл логотипа не трогаем.
- Размеры, шрифты, радиусы, анимации.

## Реализация и проверка

Один файл — `styles.css` (874 строки). Порядок: добавить блок токенов → заменить hex/rgba на `var()` по маппингу → удалить ставшие избыточными dark-правила.

Проверка:
1. `grep` по старым hex-значениям — не должно остаться ни одного вхождения (кроме значений внутри блока токенов, где старых нет по определению).
2. Открыть в браузере `index.html`, `promos.html`, по одной странице из `trading/`, `markets/`, `partnership/`, `company/`, `products/` — в обеих темах: фон, текст, кнопки, ссылки, hover, тикер (рост/падение), мегаменю, CTA-баннер, футер.
3. Отдельно проверить переключатель темы (иконки луна/солнце) и читаемость жёлтых ссылок на белом.
